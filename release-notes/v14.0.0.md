# AI 出图终端 v14.0.0 正式版

发布日期：2026年10月26日

本次为新版 AI 出图终端的首个大版本正式发布。此前 v13.5.14、v13.5.15 作为新版界面的测试与兼容完善阶段；v14.0.0 汇总这两次更新的主要能力，并加入新的图片、视频、文件整理和任务恢复功能。

## 图片与视频

- 统一支持 **Image Lab、AI中台、RunningHub** 三个渠道，在同一工作台切换模型和任务。
- Image Lab 新增 **Grok Image / Image 2.0**，以及 **Grok Video / Video 1.5 / Video 1.5 Lite**，支持文生图、图生图、文生视频和图生视频。
- 视频可选择型号对应的分辨率、1–15秒时长及音频开关，支持本地播放、查看原片和下载。
- 参考图片采用紧凑堆叠卡片，可集中查看、添加、移除及清空；重复参考图去重，坏文件不会中断整批添加。
- 保留 GPT 图片的自动尺寸与常用比例选择，选项标注横版、竖版；实际输出尺寸以模型返回为准。

## 批量翻译与素材整理

- 批量翻译提供语种搜索、智能勾选、共享模板及独立任务概要确认，普通翻译与地区货币处理按需切换。
- 保留前两版的 **147个内置地区、自定义地区、同语种多市场**及 **AI货币换算**；金额由模型处理，使用前请核对结果。
- RunningHub 支持导入 API JSON 自动识别常用输入，可添加、删除工作流并调整日常运行参数。
- 批量命名支持字段开关与顺序、可搜索的语种和品类、按选择顺序排列标签；一次执行即可完成，成功后清理本次多余备份。
- 新增 **整理文件夹**：预览后按日期、品类、语种归档，冲突与未识别文件保留原位；命名、整理后同步作品和参考图路径。

## 稳定性与恢复

- Image Lab 改为异步任务，保存私人空间及多批次记录，可从“任务队列 → 历史批次”载入并继续查询或补下载。
- 提交状态不明且超过安全期限时阻止自动重交；需要重做可单独选择“重新生成”，明确提示新任务可能产生用量。
- 已受理任务的续查不再依赖原图仍在原位置；配置 JSON 损坏时保留原文件，优先恢复有效备份。
- 补齐 Image Lab 错误码中文建议，保留服务端真实原因；任务队列区分本地等待、云端排队、生成与下载。
- 延续 v13.5.15 的旧语种配置启动修复、真实启动错误提示及升级兼容处理，减少更新后无法启动和误报 WebView2 的情况。

## 日常体验

- 延续新版 HeroUI 深浅主题和自定义标题栏，支持窗口拖动、缩放及高DPI适配，任务日志可独立打开。
- 提示词支持历史、收藏及本机草稿恢复，补充内置可搜索使用说明，左侧可一键打开输出文件夹。
- 数据统计支持按渠道、模型、任务类型、翻译目标和批次查看明细，区分生成、续查与补下载。
- 新增 **UISFX提示音**：柔和、极简、工作室三种风格，支持音量、静音及试听；批量任务结束只提示一次。
- 按渠道实际上限显示并发，降低空闲轮询频率，大队列分批显示，减少界面负担。

## 安装与升级

- 新安装推荐下载 **AI-Image-Terminal.exe**，放在有写入权限、空间充足的本地目录中运行。需要 Windows 和 Microsoft Edge WebView2 Runtime。
- 已有版本可通过“检查更新”升级；升级或手动替换时保留同目录的 **.webui-state、密钥、配置和输出素材**。更新包不包含个人配置或密钥。
- 为兼容旧版更新器，同一版本同时提供 **AI-Image-Terminal-Web-Preview.exe**，与正式文件内容相同，仅文件名不同。
- Image Lab 服务端结果保留24小时，本机已下载文件不受其到期清理影响。Grok目前适用于内部设计测试；实际比例、音频及模型可用性仍以上游为准。

验证结果：后端258项回归中245项通过、13项旧Tk界面测试按默认配置跳过；前端16项全部通过。正式EXE已验证干净启动、WebView2桌面窗口、Grok能力列表、声音设置、授权文件及v14.0.0更新版本识别；安装包未包含个人配置或密钥。
